# QA Audit Checklist

## 1. Доступность сайта
- [ ] Главная страница открывается
- [ ] Нет ошибок 4xx/5xx на основных страницах
- [ ] HTTPS работает корректно
- [ ] Нет циклических редиректов
- [ ] Время ответа не превышает допустимый порог

## 2. Навигация
- [ ] Главное меню работает
- [ ] Все основные ссылки открываются
- [ ] Нет битых внутренних ссылок
- [ ] Логотип ведёт на главную страницу
- [ ] Пользователь может вернуться назад без потери состояния

## 3. Формы
- [ ] Все формы отображаются корректно
- [ ] Обязательные поля обозначены
- [ ] Нельзя отправить форму без обязательных данных
- [ ] Email проверяется на корректность
- [ ] Телефон проверяется на корректность
- [ ] Ошибки валидации понятны пользователю
- [ ] После успешной отправки есть подтверждение
- [ ] Повторная отправка не создаёт дубликаты

## 4. Кнопки и элементы управления
- [ ] Все кнопки кликабельны
- [ ] Кнопки имеют понятные названия
- [ ] Состояния hover/focus/disabled работают корректно
- [ ] Нет элементов, которые выглядят кликабельными, но не работают
- [ ] После действия пользователь получает обратную связь

## 5. Контент
- [ ] Нет пустых блоков
- [ ] Нет технического текста или placeholder-данных
- [ ] Нет опечаток
- [ ] Заголовки соответствуют содержимому
- [ ] Изображения загружаются
- [ ] Нет сломанных изображений

## 6. Адаптивность
- [ ] Сайт корректно отображается на мобильном устройстве
- [ ] Нет горизонтального скролла
- [ ] Текст не выходит за границы блоков
- [ ] Кнопки удобно нажимать на мобильном устройстве
- [ ] Меню корректно работает на мобильной версии

## 7. Пользовательские сценарии
- [ ] Основной сценарий можно пройти от начала до конца
- [ ] Пользователь понимает следующий шаг
- [ ] Нет тупиковых экранов
- [ ] Данные сохраняются после ожидаемых действий
- [ ] Отмена действия работает корректно

## 8. Негативные сценарии
- [ ] Проверены пустые значения
- [ ] Проверены слишком длинные значения
- [ ] Проверены некорректные форматы данных
- [ ] Проверены повторные клики
- [ ] Проверено поведение при ошибке сети
- [ ] Проверено поведение при недоступности сервера

## 9. UX
- [ ] Интерфейс понятен без дополнительных объяснений
- [ ] Основные действия легко найти
- [ ] Термины и подписи понятны пользователю
- [ ] Нет лишних шагов
- [ ] Ошибки объясняют, что произошло и что делать дальше
- [ ] Важные элементы визуально заметны

## 10. Итог аудита
- [ ] Все найденные проблемы зафиксированы
- [ ] Для каждой проблемы указан severity
- [ ] Есть шаги воспроизведения
- [ ] Указан фактический результат
- [ ] Указан ожидаемый результат
- [ ] Добавлены скриншоты при необходимости
- [ ] Сформированы рекомендации
