\# Test Documentation Examples



Примеры тестовой документации для демонстрации практических навыков QA Engineer.



В папке собраны готовые примеры:



\- checklist;

\- test cases;

\- bug reports.



Документация подготовлена в формате, приближенном к рабочему QA-процессу и может использоваться как часть портфолио.



\## Содержимое



\### Checklist



Файл:



`checklist.md`



Содержит пример чек-листа для проверки веб-приложения.



Покрывает:



\- функциональность;

\- навигацию;

\- формы;

\- валидацию;

\- UI;

\- негативные сценарии;

\- базовые проверки API;

\- обработку ошибок.



\### Test Cases



Файл:



`test\_cases.md`



Содержит примеры полноценных тест-кейсов со структурой:



\- ID;

\- Title;

\- Preconditions;

\- Steps;

\- Expected Result;

\- Priority.



\### Bug Reports



Файл:



`bug\_reports.md`



Содержит примеры баг-репортов со структурой:



\- ID;

\- Title;

\- Environment;

\- Preconditions;

\- Steps to reproduce;

\- Actual Result;

\- Expected Result;

\- Severity;

\- Priority.



\## Используемые навыки



\- техники тест-дизайна;

\- ручное тестирование веб-приложений;

\- REST API;

\- DevTools;

\- Postman;

\- анализ HTTP-кодов;

\- составление тест-кейсов;

\- составление чек-листов;

\- оформление баг-репортов;

\- приоритизация дефектов.
